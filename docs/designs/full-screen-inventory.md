# 一期完整页面与弹窗清单

本清单用于完整界面方向探索，范围以 `docs/PRD.md` 的一期合同为准。每套视觉方向必须覆盖下列页面、状态和弹窗；未进入一期的账户、家庭共享、跨设备同步和备份恢复不在本轮设计中占位。

## 流程板 1：记录与解析生命周期

1. 快速记录页
   - 当前模式及默认标签
   - 单标签关闭
   - “本笔跳出模式”
   - 自然语言输入与立即保存
   - 语音预输入（同一输入区集成麦克风，非独立页面）：
     - 空闲：展示「按住说话」；按下麦克风请求权限并开始录音；可直接键入
     - 首次使用模型弹窗：约 168 MB、本地识别和可删除说明；国内 / 境外下载源显式单选；下载、校验、失败、重试和空间不足状态
     - 收音中：展示「正在听，松开结束」和可变的增量文字预览；禁用直接编辑；短暂停顿和模型端点不得提前结束
     - 完成中：用户松开后停止 PCM 采集并冲刷识别器；至多一次把最终文字合入受控原文
     - 首次授权打断按住动作：授权后提示「权限已开启，请再按住说话」，不得在用户已松手后自行录音
     - 屏幕阅读器：点按切换开始/结束，行为与默认按住/松开等价
     - 可恢复错误（中文）：权限拒绝、模型未就绪或加载失败、无语音、忙、打断等；失败不抹掉已键入原文
     - 隐私披露：不生成录音文件；模型下载完成后识别完全在本机进行
     - **不**自动点「记下来」；**不**因听写创建解析作业
2. 今日账页
   - 已入账记录
   - 待解析记录
   - 待确认记录
   - 解析失败记录
   - 同一原始输入生成的多条并列消费记录
3. 入账前确认页
   - 原始输入
   - AI 结构化结果
   - 修改、确认与拒绝
4. 普通记录详情与直接编辑
   - 金额、时间、商户、标签、模式归属
   - 原始输入只读对照
   - 保存手工修改

## 流程板 2：支付关系、模式与标签治理

1. 含优惠券抵扣的账目详情与编辑
   - 商品原价、本次实付、优惠券抵扣
   - 不展示或维护优惠券 ID、买券记录和券资产状态
2. 模式管理页与模式选择弹窗
   - 模式列表、当前启用状态、切换与关闭
3. 新建或编辑模式页
   - 模式名称
   - 多个默认标签
   - 标签选择弹窗
4. 标签管理页与合并弹窗
   - 搜索、重命名、别名
   - 选择目标标签并合并
   - 明确历史账目将统一引用目标标签
   - 未被账目或模式引用的标签可删除；仍有引用时提示先合并或移除引用

## 流程板 3：统计与筛选

1. 统计首页
   - 当前时间范围的消费概览与近期消费记录
   - 默认消费金额口径
   - 动态常用视角
   - 消费占比与趋势入口
   - 不使用固定维度一级 Tab
2. 统计筛选弹窗
   - 时间范围或模式范围
   - 可选标签筛选
   - 多标签“同时满足 / 满足任一”
   - 互斥统计组
   - 日、周、月趋势粒度
   - 消费占比选择模式时默认覆盖该模式全部时间，可选再限定日期
   - 消费趋势只展示其实际支持的时间与标签条件，不静默忽略模式
3. 消费占比结果
   - 筛选后的消费总额作为分母
   - 各桶金额与占比
   - “未归类”桶
   - 各桶合计等于总额
4. 消费趋势结果
   - 零值时间桶
   - 当前时间粒度
   - 标签筛选条件
5. 统计记录下钻页或弹窗
   - 展示构成当前桶或时间点的扁平消费记录
   - 可继续追溯原始输入
   - 「未归类」严格只包含未命中当前互斥统计组任一标签的记录

## 流程板 4：设置、导出与关键弹窗

1. 设置页
   - 默认直接入账 / 入账前确认
   - 本地数据与在线 AI 解析说明
   - AI 提供商（BYOK）入口：Endpoint、API Key（掩码）、Model、保存、测试连接/解析（计费提示）、清空、root/越狱披露
   - 模式管理、标签管理和导出入口
2. Excel 导出设置页
   - 自定义时间范围
   - 全部业务字段可选
   - 一键完整账本
   - 不导出凭据与内部任务状态
3. 导出完成弹窗
   - 文件名、范围和生成时间
   - 系统分享入口
4. 解析失败处理弹窗
   - 原文已安全保存在本机
   - 重试或手工整理
   - 不用默认值伪装成功
5. 撤销记录确认弹窗
   - 在账本或今日账长按已入账记录触发，不常驻删除图标
   - 明确撤销后不再进入统计
   - 取消与确认撤销
6. 未保存修改确认弹窗
   - 继续编辑或放弃修改

## 覆盖要求

- 三套方向使用相同页面合同，不得通过删减页面制造“更极简”的假象。
- 不得设计购物记录组、记录下子明细或专用多明细编辑页；一次原始输入产生多笔消费时，直接生成多条并列消费记录。
- 视觉可以隐藏底层类型、队列和统计实现，但不能隐藏失败、待确认、模式归属或统计筛选语义。
- 语音状态是瞬时 UI，不得做成额外卡片堆叠或独立录音时间线；模拟器验收不能冒充实机中文识别质量通过。
- 每张流程板最多承载四至五个主要手机画面；弹窗叠加在触发它的页面上。
- 生成式界面图片用于方向选择，最终界面仍需由原生组件或设计工具重建。
