# 当前最终界面方向：清简账本

本目录是当前一期界面的正式设计方向，覆盖范围以 `../full-screen-inventory.md` 为准。此前生成的设计图只作为视觉探索，不作为页面或数据结构合同。

## 设计判断

- 全局导航只有 `记录 / 账单 / 设置`。
- 默认打开记录页；记录页查看入口与底部「账单」进入同一页面。流程板 01 中原「今日账」画面的清简列表视觉继续沿用，但页面合同已收敛为“顶部待处理 + 按发生日期倒序的完整账单”，不再存在独立今日页。
- 自然语言统计是一次性意图输入，不保存聊天历史，不使用 AI 人格。
- 标签类型只保留「类目 / 其他」，不做固定一级 Tab；行程、地点、人物、用途等上下文统一显示为其他标签，商户仍是独立字段。
- 输入框旁的紧凑新增动作使用清晰的加号图标按钮，保留可读的无障碍名称，不使用拥挤的文字主按钮。
- 重复的行内新增、编辑与移除使用一致的加号、铅笔和关闭图标；保存、查看结果及危险确认仍保留文字，避免只靠图标猜测。
- 账单页先呈现待处理、消费概览和按日期分组的完整记录；分析筛选集中在一个入口，模式与时间、标签平级且有明确选中状态。
- 账单页标题下提供紧凑的本地关键字搜索；搜索态收起消费概览与分析入口，把空间让给按日期分组的匹配账单，并明确提示轻点查看、长按撤销。
- 已撤销账单不混入正常时间线；账单页提供低强调度独立入口，归档页按撤销时间列出单条账单并提供恢复操作。
- 产品界面不展示 SQLite、队列、调度、合同版本、配置修订等实现文案；仅在用户需要采取行动时解释结果与恢复方式。
- 一次原始输入可以生成多条并列消费记录；没有购物记录组、子消费明细或专用多明细编辑页。
- 清新感来自留白、比例、排版和低饱和色彩，不使用纸张拟物、玻璃拟态、装饰插画或金融仪表盘套件。

## 设计系统

- 背景：青瓷白 `#F6FAF8`
- 主表面：`#FFFFFF`
- 主文字：深墨绿 `#173B36`
- 次文字：`#71827E`
- 主强调：薄荷青 `#239D87`
- 浅层背景：水色 `#DDF3EE`
- 待解析：清蓝 `#68BCC4`
- 待确认：低饱和琥珀 `#C2933C`
- 失败与撤销：小面积珊瑚 `#D9685F`
- 分隔线：`#DCE7E3`

正文使用系统中文无衬线字体；金额使用等宽数字。层级优先依靠留白、字号和发丝线，只在确有语义整体时使用容器。
