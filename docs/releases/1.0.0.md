### 描述

花哪是一款本地优先的自然语言记账 App。

你可以像写日记一样输入“午饭在小馆吃面，花了 28 元”，也可以直接说出来。花哪会把这次输入整理成可检查、可修改的消费记录，再由你确认账目。

主要功能：

- 自然语言和本地语音记账
- 金额、商户、时间、类别与标签整理
- 多笔消费识别与逐笔管理
- 按时间、类别、标签和模式统计
- Excel 导出与系统分享
- 本机 SQLite 账本，不建立云端账本副本

AI 只接收整理当前一次输入所需的内容，不会收到完整账本。API 密钥保存在系统安全存储中，不写入账本、日志或导出文件。

### 本次更新

花哪首次发布：支持自然语言与本地语音记账、消费记录管理、统计、标签和 Excel 导出。

### 审核说明

- App 第一阶段是单人、单设备、单账本，不要求注册或登录。
- AI 设置支持用户自备 OpenAI 兼容服务。没有有效配置时，App 会明确提示配置，不会生成虚假账目。
- 设备端语音模型按用户操作下载；识别在本机完成，录音不保存为文件也不上传。
- App 使用 SQLCipher 保护本机数据库。出口合规由 App Store Connect 加密问卷确认，不预填“仅使用豁免加密”。
